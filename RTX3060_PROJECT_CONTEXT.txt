2. PROJECT QUESTION AND DATASET
------------------------------
Dataset: the RAVDESS speech recordings indexed in data/RAVDESS/index.csv.
There are 1,440 original recordings, 24 actors, and 60 recordings per actor.
Original files are organized as data/RAVDESS/Actor_XX/<recording_id>.wav.

Classification uses eight emotions, in this exact model label order:
  0 neutral
  1 calm
  2 happy
  3 sad
  4 angry
  5 fearful
  6 disgust
  7 surprised

Neutral has 96 recordings; each other emotion has 192. This class imbalance
is one reason unweighted average recall is the primary metric.
Index columns include file, emotion, intensity, actor_id, gender, statement,
repetition, duration_seconds, class_count, and actor_count.

The core extension question is whether removing some between-speaker pitch
height variation while retaining within-speaker emotional prosody improves
generalization to unseen speakers.

Terminology matters. The current method is speaker/actor-level normalization
using robust median log-F0 centres. Calling it simply "mean F0 normalization"
would misdescribe the current baseline estimator. The broad initial idea was
mean normalization, but the implementation evolved substantially.

Each complete condition has 72 seed/fold pairs and 4,287 held-out predictions:
one test prediction per matched recording per seed.

Metrics:
  UAR = arithmetic mean of the eight per-class recalls.
  WAR = overall accuracy, also called weighted average recall here.
  Additional stored outputs include macro/weighted F1, class recalls, and
  raw/row-normalized confusion matrices.

For each seed, pool predictions from all 24 test folds before computing the
reported UAR/WAR. Report mean and SAMPLE standard deviation across the three
seed-level pooled scores. Do not replace this with a mean/std over folds.
Fold checkpoints are selected by highest validation UAR, not test performance.
The current strict-improvement check keeps the earlier epoch when scores tie.

The speaker-normalized conditions use an unlabeled batch from each speaker to
estimate that speaker's baseline, including the held-out speaker's recordings.
Emotion labels are not used for baseline fitting. This is batch speaker
adaptation/calibration, not first-utterance deployment. Training speakers and
test speakers remain disjoint for supervised learning, but the batch-calibration
assumption must be disclosed explicitly.


4. MODELS AND TRAINING
----------------------
MFCC-BiLSTM:
  Librosa extraction at 16 kHz, 40 MFCCs per frame, time-by-coefficient layout.
  One bidirectional LSTM layer, hidden size 64 per direction.
  Concatenate final forward/backward hidden states: 128 dimensions.
  Linear classification into eight emotions.
  Packed sequences in the original implementation and on CUDA/CPU.
  Adam, learning rate 0.001, batch size 32, 30 epochs.

Frozen HuBERT:
  facebook/hubert-base-ls960.
  Frozen final Transformer layer, mean pooling over time, 768 dimensions.
  Newly trained 768-to-8 linear head per fold/seed.
  Adam, learning rate 0.001, batch size 32, 30 epochs.

Frozen wav2vec2:
  facebook/wav2vec2-base.
  Frozen final-layer representations, mean pooling over time, 768 dimensions.
  Same linear head and head-training hyperparameters as HuBERT.

Frozen feature extraction batches ONLY exactly equal resampled sample lengths.
This avoids padding-related changes to encoder normalization/pooling. Preserve
this detail when optimizing. Padding arbitrary lengths and averaging padded
hidden states would change the method.

HuBERT layer probing:
  Separate frozen mean-pooled representations and linear classifiers for
  Transformer layers 1 through 12. Original-audio results exist for all layers.
  Normalized layer probing is a proposal commitment but is not completed.

Backbone fine-tuning implementations:
  src/models/finetuned_hubert_linear.py
  src/models/finetuned_wav2vec_linear.py
  The code makes the backbone trainable, applies a linear head, uses batch
  size 1, learning rate 1e-5, 30 epochs, gradient checkpointing, mean temporal
  pooling, and disables SpecAugment.
  These are IMPLEMENTATIONS, not completed fine-tuning experiments.
  A frozen encoder plus a trained head is not backbone fine-tuning.

The shared loss is cross-entropy. The current runner seeds PyTorch per fold.
It is not a complete deterministic cross-platform reproducibility framework.
Record actual GPU/software settings rather than promising bitwise-equivalent
CPU/MPS/CUDA training.


5. HISTORY OF NORMALIZATION EXPERIMENTS
--------------------------------------
Stage A: Historical utterance-level Librosa normalization.
Each utterance's pYIN mean F0 was independently moved toward 200 Hz using the
older Librosa pitch-shift pipeline. Recognition deteriorated substantially.
The historical generation environment and exact per-file requested shifts
were not fully recorded. Saved waveforms remain evidence of that pipeline,
but an engine-only causal comparison cannot be inferred from them.

Stage B: Investigate measured versus perceived pitch.
The user noticed actors still sounded different despite normalization. We
examined voiced-frame selection, detector errors, synthesis, quiet regions,
and the distinction between speaker pitch height and perceived voice identity.
For an Actor 3 example, original mean pYIN F0 was about 175.25 Hz and the saved
normalized estimate was 272.55 Hz. On the 35 frames voiced in both versions,
the means were about 175.97 and 205.41 Hz. Different accepted frames can change
the summary dramatically. This did not establish ground-truth pitch.

Stage C: Utterance-level PSOLA.
Use native-rate Praat PSOLA synthesis, then resample to 16 kHz. The baseline
was still the utterance pYIN arithmetic mean. Generation included 1,436 files;
four originals had fewer than three accepted pYIN voiced frames. Performance
recovered substantially relative to the saved historical Librosa pipeline,
but remained below original audio. Engine and historical-estimation differences
were not perfectly isolated.

Stage D: Actor-level PSOLA using old pYIN means.
Estimate one actor baseline as the arithmetic mean of valid utterance mean-F0
values, then apply one constant semitone shift to every recording of that actor.
Each utterance has equal weight; this is not a pooled voiced-frame mean.
Test full shifts and clipping at +/-4 semitones. Both remained below original
audio. Some baselines were severely contaminated by quiet high-F0 estimates.

Stage E: Audit pYIN against current Praat filtered autocorrelation.
Measure all originals, compare detectors and frame masks, inspect difficult
examples, check sensitivity and synthetic signals, and use robust summaries.
This yielded the current active, strong Praat median baseline candidate.

Stage F: New robust actor-level full and capped conditions.
Keep synthesis unchanged and replace baseline estimation. All 1,440 recordings
were generated in each condition, with no exclusions. Fully align centres or
cap shifts at +/-4 semitones. Re-evaluate using the same matched cohort.
The capped condition had a small mean advantage over original for both completed
frozen encoder families. The new matched MFCC comparison was interrupted.

Stage G: Cleanup and publishing, November 24.
Retain only the best capped generated WAV condition, preserve metadata/results,
remove obsolete exploratory scripts and redundant files, fix Git/LFS tracking,
verify, and publish to the existing default branch master. The verified commit
is listed at the beginning of this file.


6. PITCH-ESTIMATION INVESTIGATION
--------------------------------
Important distinction: Praat is software containing pitch detection algorithms.
The new baseline detector was the separate official Praat 7.0.03 executable's
filtered-autocorrelation method. The synthesis Python package is older
Parselmouth 0.4.7, embedding Praat 6.1.38. They serve different roles.

pYIN reference setup:
  16 kHz, 50-800 Hz search range, 2,048-sample frame, 512-sample hop.
  The old baseline accepts finite voiced estimates, including many estimates
  in quiet regions, then averages in linear Hz.

Current Praat audit:
  10-ms pitch step, 50-Hz floor, 800-Hz top, 15 candidates.
  Filtered-autocorrelation settings are recorded in src/audit_pitch.praat and
  analysis/pitch_validation/f0_audit/config.json.
  Additional passes compare native-rate audio and a 1,200-Hz top.
  Actual Praat frame times are parsed; nearest-frame matching is allowed only
  within 5 ms. No interpolation across unvoiced regions.

Activity selection:
  32-ms RMS window, centred on the measurement grid;
  accept frames at least -35 dB relative to the recording's maximum RMS;
  exclude digital silence through an absolute floor.
  This is a pragmatic activity mask, not a validated speech/voicing labeler.

Strong Praat selection:
  Frame is active, voiced/finite, and selected-candidate autocorrelation
  strength is at least 0.6. Strength is not a probability of correct F0.

Robust speaker baseline:
  z = 12 * log2(F0 / 100 Hz).
  Take the median z over accepted frames in each utterance.
  Require at least ten accepted frames per utterance.
  Take the median of these utterance medians across an actor's recordings.
  Convert back: baseline_Hz = 100 * 2**(actor_median_z / 12).
  All 60 utterances qualify for every actor under the current candidate.

Examples of the correction:
  Actor 3: old baseline 232.54 Hz; robust candidate 159.71 Hz.
           Old shift -2.61 ST; robust shift +3.90 ST.
  Actor 5: old 443.46 Hz; robust 146.59 Hz.
           Old shift -13.79 ST; robust shift +5.38 ST.
  Actor 13: old 370.42 Hz; robust 131.98 Hz.
            Old shift -10.67 ST; robust shift +7.20 ST.
  Actor 21: old 101.44 Hz; robust 115.19 Hz.
            Old shift +11.75 ST; robust shift +9.55 ST.

For Actor 5, removing quiet frames alone changes the old mean-Hz shift from
-13.79 to +1.11 ST; active pYIN median gives +3.70 ST; active Praat median gives
+5.38 ST. Detector, activity mask, and statistic all matter. Do not attribute
the whole improvement simply to replacing pYIN with Praat.

Audit findings:
  - 28,813 of 91,653 pYIN voiced frames were outside the activity mask (31.4%).
    Outside the mask does not automatically mean every frame was invalid.
  - On 48,766 shared active frames, 23.4% differed by more than 1 ST.
    These are detector disagreements, not labeled errors.
  - A high pYIN probability threshold loses too much coverage for some actors;
    it was not adopted as a universal baseline gate.
  - Native-rate versus 16-kHz Praat centres differed very little in this audit;
    no evidence identified resampling as the main baseline problem.
  - Increasing the search top can change filtering/voicing selection, not just
    permit higher numerical pitches. Actor-centre sensitivity reached 0.873 ST.
  - Quality flags were retained, not used for per-test-actor tuning or removal.
  - Whole-utterance bootstrap intervals quantify sampling stability, not true
    physical F0 accuracy. Frames are overlapping observations, not independent.

Validation included 57 engine/signal combinations: tones, harmonic signals,
noisy harmonic signals, and silence. Clean controls passed the recorded error
and voiced-coverage criteria. One noisy 700-Hz Praat/top-800 stress case missed
the criterion (about 0.248-ST median error); it was reported, not discarded.
Thirty-six difficult real-speech review figures were generated. Only selected
windows were directly inspected; not every frame was manually adjudicated.
At least one local Praat subharmonic error remained despite high strength.

Conclusion: baseline estimation became better controlled, more robust, and
more defensible. We did NOT obtain hand-labeled ground-truth F0 or prove every
new frame estimate more accurate. "Spot on" is too strong a claim.


7. CURRENT NORMALIZATION AND SYNTHESIS
--------------------------------------
Let b_s be speaker s's robust baseline in semitones relative to 100 Hz.
The historical fixed target is 200 Hz, so target t = 12 ST.
Full requested shift: d_s = t - b_s = 12 * log2(200 / baseline_Hz_s).
Capped shift: applied_s = clip(d_s, -4, +4).
Apply this SAME shift to all utterances of speaker s.

Synthesis:
  Read original native-rate mono waveform.
  Parselmouth/Praat To Manipulation with 10-ms time step and 50-800-Hz limits.
  Extract pitch tier; multiply frequencies by 2**(applied_s / 12).
  Replace pitch tier; resynthesize with overlap-add PSOLA.
  Resample to 16 kHz and save FLOAT WAV.
  Verify finite samples, duration/sample count, sample rate, and hashes.

No gain matching is applied to training audio. Listening exports separately
match RMS and limit playback peaks; those gains are not part of the model data.
Some FLOAT WAV peaks exceed 1 without integer clipping. Historical measurements
found four full-shift and three capped files above 1, maximum about 1.0358.
Do not silently clip or normalize these data and reuse old manifests.

An ideal constant frequency multiplier preserves pitch ratios and adds a
constant in semitone space. It preserves within-speaker semitone variance and
relative pitch differences between utterances. Linear-Hz variance scales by
the SQUARE of the multiplier. Do not claim all kinds of pitch variance remain
unchanged. Real synthesis/voicing estimates can introduce deviations.

Actor-level normalization does not force each utterance to 200 Hz. An actor
with a 160-Hz baseline and utterance means 120/240 Hz would ideally become
150/300 Hz after multiplying by 1.25. The emotional difference remains.

Acoustic checks of the new conditions:
  All 2,880 generated outputs were remeasured with current Praat.
  Original robust actor centres: 98.89-294.05 Hz.
  Full-shift measured centres: 196.51-207.68 Hz.
  Full maximum target residual: about 0.652 ST.
  Capped measured centres: 125.05-237.74 Hz; this is partial normalization.
  Median per-recording absolute discrepancy between requested and measured
  median shift: about 0.0189 ST full / 0.0190 ST capped.
  About 5% of selected shared frames differ from the requested shift by >1 ST.
  Detector ambiguity, transitions, alignment and synthesis errors are not
  separately identified by that last number.

Fourteen actors request shifts beyond 4 ST. Ten actors are unaffected by the
cap: their 600 full/capped output recordings had identical decoded samples.

Matching an F0 centre does not match formants, spectral envelope, voice quality,
pitch spread, articulation, or identity. Actors can still sound unlike each
other even if this pitch-height statistic is closely aligned.

9. REALISTIC SCIENTIFIC INTERPRETATION
-------------------------------------
What we achieved:
  A reproducible investigation of a failing normalization pipeline;
  identification of consequential unreliable baseline estimates;
  a robust speaker-centre estimation procedure with explicit assumptions;
  synthesis and acoustic validation;
  controlled matched comparisons on two frozen encoder families;
  a small consistent-direction mean gain for the capped procedure;
  evidence that complete pitch-centre alignment is not automatically optimal.

This is a worthwhile fourth-year project contribution and a useful basis for
further work. It does not yet establish a novel publishable discovery, a
statistically reliable SER improvement, or generalization beyond this corpus.
Speaker-relative pitch normalization itself is not a newly invented concept.
A publication claim needs a careful literature review and stronger controls.

The large recovery over the poor historical normalized baseline is useful,
but an increase relative to a flawed baseline is not the same as outperforming
original audio. The small original-audio gains need a cautious interpretation.

Why might the cap help? Hypotheses, NOT established mechanisms:
  - Large shifts cause more synthesis distortion or encoder-domain mismatch.
  - Full normalization removes absolute pitch information useful for emotions.
  - The baseline is uncertain, and capping limits damage from estimation error.
  - The 200-Hz target is not optimal.
  - Small observed differences partly reflect training/data variation.
We need controls to distinguish these explanations.

15. SOFTER SHIFTS AND OTHER PROPOSED INVESTIGATIONS
--------------------------------------------------
EVERYTHING IN THIS SECTION IS PROPOSED, NOT A COMPLETED RESULT.
"Tonal median" is interpreted here as an estimated speaker pitch centre in
log-frequency space, not a linguistic-tone label or a validated habitual F0.

15.1 Partial movement toward a target
Let d_s = t - b_s. Apply alpha*d_s, with alpha between 0 and 1.
  alpha=0: no pitch movement.
  alpha=1: full centre alignment.
  intermediate alpha: retain some between-speaker pitch variation.
Small exploratory candidates could be alpha=0.25 and 0.5, alongside existing
original/full/cap references. Select alpha by validation, not repeated test
inspection. Do not run a large grid just because frozen heads are inexpensive;
each waveform condition needs synthesis/extraction and creates selection bias.

An alpha=0 PSOLA export is a zero-shift RESYNTHESIS control, not necessarily
identical to original audio. Keep original and zero-shift PSOLA distinct.

15.2 Smooth bounded shifts
Instead of hard clipping, consider applied_s = C*tanh(d_s/C).
Small shifts are approximately unchanged; large requests saturate smoothly.
This is not the same transformation as clip(d_s,-C,C), and it is not yet tested.
Hard clipping is continuous; the distinction is its change in slope at the
boundary, not a discontinuity in the applied shift value.

15.3 Combining soft movement and a cap
alpha*clip(d_s,-C,C) differs from clip(alpha*d_s,-C,C).
For d_s=8, C=4, alpha=0.5, the former gives 2 ST and the latter 4 ST.
Choose the definition explicitly and save the actual per-speaker shifts.

15.4 Target a training-speaker median instead of arbitrary 200 Hz
For each LOSO fold, compute t_fold from the baseline centres of TRAINING actors
only, for example their median in semitone space with equal speaker weights.
Use that target for the corresponding train/validation/test condition.
Do not compute a supposedly training-only target from all 24 speakers.
Fold-specific targets mean one actor can need different transformed versions
across folds: architecture/data caching must represent fold-specific artifacts
or apply transformations during the appropriate fold. One global actor WAV
folder cannot encode every fold-specific target simultaneously.

The existing method's access to an unlabeled test-speaker calibration batch is
already an explicit protocol assumption. A train-derived target does not turn
the procedure into first-utterance inference.

15.5 Move toward an acceptable target range
Choose a training/validation-defined interval [L,U] in semitones and apply
clip(b_s,L,U)-b_s. Speakers inside the interval are not moved; speakers outside
are moved toward the nearest boundary. This tests whether reducing extremes
is preferable to forcing all voices to one pitch centre.

15.6 Deadband near the target
An alternative is sign(d_s)*max(abs(d_s)-delta,0), optionally bounded afterward.
This leaves sufficiently close speakers alone and avoids full convergence.
Define delta through a fixed rationale/validation protocol, not test tuning.

15.7 Confidence-weighted movement
Reduce movement when the baseline is unstable or coverage is poor; define
alpha_s using prespecified uncertainty/coverage summaries. High AC strength
alone is insufficient. Bootstrap widths describe sampling stability, not a
calibrated probability of correctness. Shrinking a baseline toward the target
before shifting can be algebraically equivalent to scaling d_s; do not count
equivalent parameterizations as separate discoveries.

15.8 Component ablations for stronger causal claims
Keep detector/frame selection fixed while comparing mean versus median in
semitones. Keep the statistic fixed while changing activity selection. Keep
mask/statistic fixed where meaningful while comparing pYIN and Praat, and
report differences in coverage rather than silently dropping difficult actors.
The current old-to-new comparison changes detector, mask and statistic together.

15.9 Zero-shift resynthesis and related controls
Zero-shift PSOLA helps isolate synthesis/resampling effects. A stronger
alignment-specific control could randomly reassign the same actor-shift
distribution across speakers with fixed seeds, but this adds work and needs
careful interpretation. Do not confuse a control's randomization seed with
training seeds or tune its assignment using test scores.

15.10 Other extensions, mostly after the deadline
  - A small separate unlabeled calibration subset per test speaker, with
    disjoint evaluation utterances and a revised matched protocol.
  - Baseline stability versus calibration-set size.
  - Cross-corpus evaluation and broader speaker/language coverage.
  - Robust handling of short/unvoiced utterances and detector octave glitches.
  - Acoustic-quality/listening assessment under controlled gains.
  - Representation-level speaker-pitch normalization as a different method.

Do not normalize every utterance independently in a new "soft speaker" test;
that would again risk removing between-utterance emotional pitch differences.


16. EXPERIMENT DESIGN AND STATISTICAL DISCIPLINE
------------------------------------------------
Before each new experiment, write down:
  question; condition formula; actor calibration scope; target source;
  selected cohort and split hashes; model/layer; versions and precision;
  seeds/folds/epochs; validation selection; required controls; output paths.

Generate from ORIGINAL recordings, not an already shifted waveform. Repeated
resynthesis compounds processing and makes shift comparisons harder to interpret.
Keep each new condition separate and export applied shifts, source hashes,
sample rates/counts, finite/peak checks, exclusions, versions, and provenance.

Use the same samples, splits and training settings within a comparison. Do not
allow a different exclusion set or hardware/precision change to masquerade as
an alpha/cap improvement. New fold-specific policies need their own careful
data handling and cannot simply reuse the historical fixed global folders.

Validation chooses settings; final held-out tests assess them. Since historical
test scores have already influenced interest in capped normalization, describe
the development as exploratory. A new sweep over the same tests is not fresh
confirmation. Avoid optimizing each held-out actor's shift to its emotion score.

Report paired deltas as percentage POINTS, not percent relative improvement.
For uncertainty, use paired speaker-level summaries where appropriate; do not
bootstrap individual frames as independent speakers. Three seed scores alone
do not justify a confident significance claim. Disclose limitations of actor
resampling and overlapping LOSO training sets.
